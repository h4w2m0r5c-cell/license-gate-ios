# iOS 授权验证

打开后自动要求验证码。

- 首次输入 `1234`：关闭弹窗，可使用 30 天
- 到期后再次打开，输入 `2234`：永久解锁
- 永久解锁后不再弹窗

## 现在就能装到 iPhone

iOS 不允许像安卓 APK 那样从 GitHub 直接下载安装。没有你的 Apple 开发者证书，GitHub 也打不出可安装的 IPA。

请用 Safari 打开部署后的页面，点底部分享，选择「添加到主屏幕」。之后从主屏幕图标打开，行为与 App 一致。

## 真正的 iOS App

用 Mac 打开 `LicenseGate.xcodeproj`，选择你的 Apple ID 签名，再跑到手机。个人免费账号签名的安装大约 7 天后要重签。
